# FIGlet (.flf)

Arquivos tradicionais FIGfont para exemplos e testes do módulo
\`Graphics/FIGlet\`:

- Cosmeron.flf
- Cosmeron-ASCII.flf
- Cosmeron-Bold.flf
- Cosmeron-Bold-ASCII.flf
- NibbleBits.flf

Essas fontes pertencem ao projeto Cosmeron e são documentadas nos próprios
arquivos como EUPL-1.2-or-later.

O formato \`.asf\` nativo C11 permanece separadamente em
\`Codespace/Cosmeron/Modules/Graphics/Font/Fonts/\`.
