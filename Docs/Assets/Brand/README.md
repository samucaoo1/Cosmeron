# Cosmeron Brand Assets

This directory contains the full-resolution visual identity assets used by the Cosmeron repository and its documentation.

- `Cosmeron.png` — square logo with symbol and wordmark, full-resolution PNG.
- `Cosmeron-Horizontal.png` — horizontal logo and wordmark; canonical README banner, full-resolution PNG.
- `Cosmeron-Icon.png` — icon-only mark without the Cosmeron wordmark, full-resolution PNG.

The PNG masters are kept at their generated resolution without JPEG conversion or downscaling. Keep brand assets under `Docs/Assets/Brand/` so the repository root remains focused on source discovery and project entry points.
