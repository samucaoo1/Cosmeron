# Cosmeron Brand Assets

This directory contains the visual identity assets used by the Cosmeron repository and its documentation.

- `Cosmeron.jpg` — original square logo with symbol and wordmark.
- `Cosmeron-Horizontal.jpg` — horizontal logo and wordmark; canonical README banner.
- `Cosmeron-Icon.jpg` — icon-only mark without the Cosmeron wordmark.

Keep brand assets under `Docs/Assets/Brand/` so the repository root remains focused on source discovery and project entry points.
