# Security Policy

[Português (Brasil)](../Translations/Portugues-Brasil/Governance/SECURITY.md) · [Español (Latinoamérica)](../Translations/Espanol-LATAM/Governance/SECURITY.md)

Cosmeron is currently experimental and under active development.

## Reporting a vulnerability

Please do not publish sensitive vulnerability details, credentials, private keys,
tokens, or working exploits in a public issue.

Use this repository's **Private vulnerability reporting** feature:
open the **Security** tab and choose **Report a vulnerability**.

For non-sensitive security hardening, suspected bugs without confidential
details, or already-public issues, a normal GitHub issue is appropriate.

## Supported versions

Until Cosmeron reaches a stable release, security fixes target the
current development line. Older experimental revisions are not guaranteed to
receive backports.
