# Support

Cosmeron is an experimental open-source project under active development.

For reproducible defects, use the **Bug report** issue form. For API, module, or architectural proposals, use the **Feature request** form.

When asking for help, include the smallest useful context: the Cosmeron revision, compiler and version, operating system, relevant include path, compile command, and a minimal C11 example when possible.

Security-sensitive reports must follow the [Security Policy](SECURITY.md) and should be submitted through GitHub Private vulnerability reporting instead of a public issue.

Support is best-effort. Questions that produce generally useful answers may be incorporated into the documentation.
