# Cast

The **Cast** core module provides declarative infrastructure and operational implementations for type conversions with robust bounds checking.

```c
#include "Cosmeron/Core/Cast/Cast.h"
/* or selectively: */
#include "Cosmeron/Core/Cast/Converting.h"
#include "Cosmeron/Core/Cast/Integer.h"
#include "Cosmeron/Core/Cast/Float.h"
```

---

# Overview

The Cast framework includes:
1. **Namespace & Naming Conventions (`Cast.space`):** Standard tokens and macros to construct namespaced function identifiers.
2. **Declarative Cast Engine (`Converting.h`):** The `CONVERTING` family of macros allowing single-line or block declarations and implementations of conversion routines without boilerplate.
3. **Integer & Size Conversions (`Integer.h` / `Integer.impl`):** Complete set of checked integer conversions for 8, 16, 32, 64-bit signed/unsigned types and `size_t`.
4. **Floating-Point Conversions (`Float.h` / `Impl/Float.impl`):** Checked floating-point conversions between `float`, `double`, and integer types with strict bounds and `NaN`/$\pm\infty$ validation.

---

# Function Signature & Error Contract

All conversion functions generated by the Cast engine follow the canonical signature:

```c
OPSTATUS <Target>_<From>to<To>(<from_type> inValue, <to_type> *outValue);
```

For methods defined on `OBJECT` targets, the receiver is bound as the first parameter:
```c
OPSTATUS <Target>_<From>to<To>(<Target> *self, <from_type> inValue, <to_type> *outValue);
```

### Return Values & Error Handling

- **`STATUS_CONST(INVALID_ARGUMENT)`**: Returned when `outValue == NULL` (or `self == NULL` for object methods). The destination pointer is left untouched.
- **`STATUS_CONST(ARITHMETIC_OVERFLOW)`**: Returned when `inValue` exceeds the valid range defined by the conversion rule or explicit limits, or when input is `NaN` / $\pm\infty$ for integer conversion. The destination pointer is left untouched.
- **`STATUS_CONST(SUCCESS)`**: Returned when the value fits within limits. `*outValue` is assigned the converted value: `*outValue = (<to_type>)inValue`.

# Declarative Engine (`Converting.h`)

The declarative engine eliminates repetitive conversion boilerplates by mapping specification tuples to clean, warning-free inline C functions.

### Specification Tuples

| Macro | Signature | Description |
| --- | --- | --- |
| `TO(Name, Type, Category)` | `TO(TO_NAME, TO_TYPE, ESPECIAL)` | Conversion without extra bound expressions (e.g., widening conversions or non-negative checks). |
| `TO_EX(Name, Type, Category, ...)` | `TO_EX(TO_NAME, TO_TYPE, ESPECIAL, LIMITS...)` | Conversion with explicit limit expressions (`MAX` for single bound, `MIN, MAX` for signed range). |

### Category & Bounds Matrix

| `Category` / `ESPECIAL` | Extra Limits | Generated Validation Check | Primary Use Case |
| --- | --- | --- | --- |
| `SIGNED` | None | *(None — infallible)* | Widening to signed (`Uint8` $\to$ `I16`/`I32`/`I64`, `Int8` $\to$ `I16`/`I32`) |
| `UNSIGNED` | None | `inValue < 0` | Signed to wider/equal Unsigned (`Int32` $\to$ `U32`/`U64`/`Size`) |
| `UNSIGNED` | `MAX` | `(uint64_t)inValue > (uint64_t)(MAX)` | Unsigned downcast (`Uint64` $\to$ `32`) or Unsigned to Signed (`Uint64` $\to$ `I8` with `INT8_MAX`) |
| `UNSIGNED` | `MAX` *(when source signed)* | `inValue < 0 \|\| (uint64_t)inValue > (uint64_t)(MAX)` | Signed to narrower Unsigned (`Int64` $\to$ `U8` with `UINT8_MAX`) |
| `SIGNED` | `MIN, MAX` | `inValue < (FROM_TYPE)(MIN) \|\| inValue > (FROM_TYPE)(MAX)` | Signed downcast (`Int64` $\to$ `32`, `Int32` $\to$ `I8`) |
| `FLOAT` | None | *(None — infallible)* | Widening float (`Float` $\to$ `Double`) or Integer to Float (`Int32` $\to$ `Float`/`Double`) |
| `FLOAT` | `MAX` | `isnan(inValue) \|\| inValue < -(double)(MAX) \|\| inValue > (double)(MAX)` | Float downcast (`Double` $\to$ `Float` with `FLT_MAX`) |
| `SIGNED` *(when source float)* | `MIN, MAX` | `isnan(inValue) \|\| inValue < (double)(MIN) \|\| inValue > (double)(MAX) \|\| inValue >= 9223372036854775808.0` | Float/Double to Signed Integer (`Float`/`Double` $\to$ `I64`/`I32`/`I16`/`I8`) |
| `UNSIGNED` *(when source float)* | `MAX` | `isnan(inValue) \|\| inValue < 0.0 \|\| inValue > (double)(MAX) \|\| inValue >= 18446744073709551616.0` | Float/Double to Unsigned Integer (`Float`/`Double` $\to$ `U64`/`U32`/`U16`/`U8`/`Size`) |

Descriptive aliases are also supported for clarity: `UNSIGNED_DOWNCAST`, `SIGNED_DOWNCAST`, `SIGNED_TO_UNSIGNED`, `UNSIGNED_TO_SIGNED`, `FLOAT_FLOAT_DOWNCAST`, and `WIDER`.

### Source Type Resolution

The source type (`FROM_SPEC`) passed as the first argument to `CONVERTING*` macros can be either:
1. **A symbolic primitive token:** `Uint64`, `Uint32`, `Uint16`, `Uint8`, `Int64`, `Int32`, `Int16`, `Int8`, `Float`, `Float32`, `F32`, `Double`, `Float64`, `F64`, `LongDouble`, `Size`, `PtrDiff`, `IntPtr`, `UIntPtr`.
2. **An explicit tuple:** `(Name, c_type)` or `(Name, c_type, SIGNED/UNSIGNED/FLOAT)` for custom domain types.

# Declarative Macros

### 1. `CONVERTING(FROM_SPEC, ...)`
Declares and implements standalone conversion functions in the `Cast` module namespace (`Cast_<From>to<To>`).

```c
CONVERTING(
    Uint64,
    TO_EX(32, uint32_t, UNSIGNED, UINT32_MAX),
    TO_EX(16, uint16_t, UNSIGNED, UINT16_MAX),
    TO_EX(I8, int8_t,   UNSIGNED, INT8_MAX)
)
```

### 2. `CONVERTING_TARGET(TARGET, FROM_SPEC, ...)`
Implements conversions for a specific `PACKAGE` or `OBJECT` target using the unified `OPERATION_IMPLEMENT_EX` dispatcher.
- Automatically handles `(self)` receiver validation when the target is an `OBJECT`.
- Emits free functions when the target is a `PACKAGE`.

```c
/* In package implementation: */
CONVERTING_TARGET(
    MyPackage,
    Uint64,
    TO_EX(U16, uint16_t, UNSIGNED, UINT16_MAX)
)

/* In object implementation: */
#define TMyObject_IS_OBJECT 1
CONVERTING_TARGET(
    TMyObject,
    Int16,
    TO_EX(I8, int8_t, SIGNED, INT8_MIN, INT8_MAX)
)
```

### 3. `CONVERTING_OPERATIONS(FROM_SPEC, ...)` & `CONST_CONVERTING_OPERATIONS(FROM_SPEC, ...)`
Used inside declarative blocks (`PACKAGE(...)` or `OBJECT(...)`) to emit `OPERATION` or `CONST_OPERATION` declarations and function table entries.

```c
PACKAGE(
    MyPackage,
    CONVERTING_OPERATIONS(
        Uint64,
        TO_EX(U16, uint16_t, UNSIGNED, UINT16_MAX)
    )
);
```

### 4. `CONVERTING_INLINE(FROM_SPEC, ...)` & `CONST_CONVERTING_INLINE(FROM_SPEC, ...)`
Used inside `PACKAGE(...)` declarations to emit inline `OPERATION_INLINE` definitions.

```c
PACKAGE(
    MyPackage,
    CONVERTING_INLINE(
        Uint32,
        TO_EX(U8, uint8_t, UNSIGNED, UINT8_MAX)
    )
);
```

### 5. `OBJECT_CONVERTING_INLINE(FROM_SPEC, ...)` & `OBJECT_CONST_CONVERTING_INLINE(FROM_SPEC, ...)`
Used inside `OBJECT(...)` declarations to emit inline methods with automatic `self` pointer validation.

```c
OBJECT(
    TConvertObject,
    FIELDS(int dummy;),
    OBJECT_CONVERTING_INLINE(
        Int32,
        TO_EX(I8, int8_t, SIGNED, INT8_MIN, INT8_MAX)
    )
);
```

# Standard Integer Conversions (`Integer.h`)

The `LIB_PREFIX(CAST_MOD)` package provides 43 built-in checked conversion functions covering all standard combinations:

- **From `Uint64`:** `Uint64to32`, `Uint64to16`, `Uint64to8`, `Uint64toI64`, `Uint64toI32`, `Uint64toI16`, `Uint64toI8`, `Uint64toSize`.
- **From `Uint32`:** `Uint32to16`, `Uint32to8`, `Uint32toI64`, `Uint32toI32`, `Uint32toI16`, `Uint32toI8`.
- **From `Uint16`:** `Uint16to8`, `Uint16toI64`, `Uint16toI32`, `Uint16toI16`, `Uint16toI8`.
- **From `Uint8`:** `Uint8toI64`, `Uint8toI32`, `Uint8toI16`, `Uint8toI8`.
- **From `Int64`:** `Int64to32`, `Int64to16`, `Int64to8`, `Int64toU64`, `Int64toU32`, `Int64toU16`, `Int64toU8`, `Int64toSize`.
- **From `Int32`:** `Int32to16`, `Int32to8`, `Int32toU64`, `Int32toU32`, `Int32toU16`, `Int32toU8`, `Int32toSize`.
- **From `Int16`:** `Int16to8`, `Int16toU64`, `Int16toU32`, `Int16toU16`, `Int16toU8`.
- **From `Int8`:** `Int8toU64`, `Int8toU32`, `Int8toU16`, `Int8toU8`.
- **From `Size`:** `SizetoU64`, `SizetoU32`, `SizetoU16`, `SizetoU8`, `SizetoI64`, `SizetoI32`.

# Standard Floating-Point Conversions (`Float.h`)

The `GNS2(LIB_PREFIX(CAST_MOD), Float)` package and `Cast` namespace provide built-in checked conversions between floating-point types (`float`, `double`, `long double`) and integers:

- **From `Float` (`float`):**
  - `FloattoDouble`, `FloattoLongDouble`: Widening conversions (infallible).
  - `FloattoI64`, `FloattoI32`, `FloattoI16`, `FloattoI8`: Signed integer conversions with range and `NaN` checking.
  - `FloattoU64`, `FloattoU32`, `FloattoU16`, `FloattoU8`, `FloattoSize`: Unsigned integer conversions with non-negative, range, and `NaN` checking.
- **From `Double` (`double`):**
  - `DoubletoFloat`: Checked downcast to `float` (overflow if exceeding `FLT_MAX` or `NaN`/$\pm\infty$).
  - `DoubletoLongDouble`: Widening conversion (infallible).
  - `DoubletoI64`, `DoubletoI32`, `DoubletoI16`, `DoubletoI8`: Signed integer conversions with range and `NaN` checking.
  - `DoubletoU64`, `DoubletoU32`, `DoubletoU16`, `DoubletoU8`, `DoubletoSize`: Unsigned integer conversions with non-negative, range, and `NaN` checking.
- **From `LongDouble` (`long double`):**
  - `LongDoubletoFloat`, `LongDoubletoDouble`: Checked downcast to narrower floating-point types (`FLT_MAX` / `DBL_MAX` and `NaN` checking).
  - `LongDoubletoI64`, `LongDoubletoI32`, `LongDoubletoI16`, `LongDoubletoI8`: Signed integer conversions with range and `NaN` checking.
  - `LongDoubletoU64`, `LongDoubletoU32`, `LongDoubletoU16`, `LongDoubletoU8`, `LongDoubletoSize`: Unsigned integer conversions with non-negative, range, and `NaN` checking.
- **From Integers to `Float` / `Double` / `LongDouble`:**
  - `Int64toFloat`, `Int64toDouble`, `Int64toLongDouble`
  - `Int32toFloat`, `Int32toDouble`, `Int32toLongDouble`
  - `Uint64toFloat`, `Uint64toDouble`, `Uint64toLongDouble`
  - `Uint32toFloat`, `Uint32toDouble`, `Uint32toLongDouble`
  - `SizetoFloat`, `SizetoDouble`, `SizetoLongDouble`

### Example Usage

```c
#include "Cosmeron/Core/Cast/Cast.h"

int32_t intVal = 0;
OPSTATUS status = Cast_FloattoI32(123.45f, &intVal);
if (status == STATUS_CONST(SUCCESS)) {
    /* intVal == 123 */
}

float fVal = 0.0f;
status = Cast_DoubletoFloat(1e40, &fVal);
if (status == STATUS_CONST(ARITHMETIC_OVERFLOW)) {
    /* Overflows 32-bit float */
}

/* Invocation via FunctionTable: */
status = PACKAGE_CALL(LIB_PREFIX(CAST_MOD), FloattoI32, 77.0f, &intVal);
```

# Struct Naming Macros (`Cast.space`)

| Macro | Purpose |
| --- | --- |
| `CAST_TYPE_TO_STRUCT(SUFFIX, TYPE)` | Generates symbol `Cast_<SUFFIX>_To_<TYPE>` |
| `CAST_STRUCT_TO_TYPE(TYPE, SUFFIX)` | Generates symbol `Cast_<TYPE>_To_<SUFFIX>` |

These helper macros compose identifiers for bidirectional conversions between primitive values and composite structs (e.g. `TPair`, `TTriple`, `TQuad`).

# Requirements

- C11 compliant compiler.
- `Core/Error/Status.h` for `OPSTATUS` return types.
- `Core/Module` framework for `PACKAGE` and `OBJECT` declarations.
- Standard C headers: `<float.h>`, `<math.h>`, `<limits.h>`, `<stdint.h>`, `<stdbool.h>`, `<stddef.h>`.
- No dynamic memory allocation or external runtime dependencies.
