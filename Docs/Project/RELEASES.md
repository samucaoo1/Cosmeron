# Cosmeron — Release Log

Cosmeron does **not** use semantic versioning for canonical releases.

Public releases are identified by the library's accumulated **Entropy**:

```text
Entropy: <absolute H><Greek band>
```

The numeric value is accumulated change in **H**; the Greek suffix identifies the current band. See [ENTROPY.md](ENTROPY.md) for the full model.

## Current state

**No canonical Cosmeron release has been published yet.**

The repository is being prepared from the latest pre-migration project state. The first public Cosmeron release will establish the `entropy-origin` tag and its initial entropy value `H₀`.

The predecessor project used the name **Congro;Library**. Its historical release and development records remain historical context; Cosmeron's public release series starts from the first source state published under the Cosmeron identity.

## Release numbering

There are no `1.0.0`, `1.1.0`, or `2.0.0` release numbers in the canonical scheme.

Examples:

```text
18866β  example release state
19124β  later state
20037γ  later state after a band transition
```

The absolute entropy number never resets.

> Every release has a history. Cosmeron measures how much history accumulated.
