# Política de Seguridad

[Português (Brasil)](../../Portugues-Brasil/Governance/SECURITY.md) · [English](../../../Governance/SECURITY.md)

Cosmeron se encuentra actualmente en fase experimental y en desarrollo activo.

## Informar una vulnerabilidad

Por favor, no publiques detalles sensibles sobre vulnerabilidades, credenciales, claves privadas,
tokens ni exploits funcionales en una issue pública.

Usá la función **Private vulnerability reporting** de este repositorio:
abrí la pestaña **Security** y elegí **Report a vulnerability**.

Para mejoras de seguridad que no involucren información sensible, sospechas de bugs sin
detalles confidenciales o problemas que ya sean públicos, una issue normal de GitHub es apropiada.

## Versiones compatibles

Hasta que Cosmeron alcance una versión estable, las correcciones de seguridad se aplican
a la línea de desarrollo actual. No se garantiza el backport de correcciones a revisiones
experimentales anteriores.
