# Política de Segurança

[Español (Latinoamérica)](../../Espanol-LATAM/Governance/SECURITY.md) · [English](../../../Governance/SECURITY.md)

Cosmeron está atualmente em fase experimental e em desenvolvimento ativo.

## Relatando uma vulnerabilidade

Por favor, não publique detalhes sensíveis sobre vulnerabilidades, credenciais, chaves privadas,
tokens ou exploits funcionais em uma issue pública.

Use o recurso **Private vulnerability reporting** deste repositório:
acesse a aba **Security** e escolha **Report a vulnerability**.

Para melhorias de segurança que não envolvam informações sensíveis, suspeitas de bugs sem
detalhes confidenciais ou problemas que já sejam públicos, uma issue comum no GitHub é apropriada.

## Versões suportadas

Até que Cosmeron alcance uma versão estável, as correções de segurança têm como alvo
a linha atual de desenvolvimento. Não há garantia de backports para revisões experimentais
mais antigas.
