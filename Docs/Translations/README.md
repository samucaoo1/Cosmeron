# Translations

Cosmeron's canonical technical and governance documentation is written in English. Maintained translations live here so localized documentation does not clutter the repository root.

- [Português (Brasil)](Portugues-Brasil/README.md)
- [Español (Latinoamérica)](Espanol-LATAM/README.md)

When a translation and the English canonical document disagree, the English project document should be treated as the current project reference. For the EUPL itself, use an official linguistic version published by the European Union.
