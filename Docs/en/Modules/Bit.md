# Bit

The **Bit** module provides scalar bit manipulation for unsigned integer widths and a fixed-size bitset template. It belongs to **Core**. Use scalar packages for one integer value and a bitset object for collections of bits.

~~~c
#include "Cosmeron/Core/Bit/Bit.h"
#include "Cosmeron/Core/Bit/Bitset.h"
~~~

`Bit.h` instantiates packages for `uint8_t`, `uint16_t`, `uint32_t` and `uint64_t`. `Bitset.h` provides fixed-capacity bitset templates.

---

# Scalar API

The scalar packages are generated by `TEMPLATE_Bit(SUFFIX, TYPE)`, with suffixes `8`, `16`, `32` and `64`. Use `MODULE_FUNC(Bit, width, Function)` to access the generated functions.

| Category | Functions | Contract |
| --- | --- | --- |
| Individual bit | `Set`, `Clear`, `Flip`, `Check` | Mutations return `OPSTATUS`; Check returns `bool` |
| Mask | `Mask.Set`, `Mask.Clear`, `Mask.Flip` | In-place procedures |
| Mask queries | `Mask.CheckAll`, `Mask.CheckAny` | `bool` |
| Mask construction | `Mask.Range(high, low, outMask)` | `OPSTATUS` |
| Counts | `Popcount`, `Count.LeadingZeros`, `Count.TrailingZeros` | `size_t` |
| Properties | `Parity`, `IsPowerOfTwo` | `bool` |
| Powers of two | `FloorPowerOfTwo`, `NextPowerOfTwo` | Value or status/output |
| Logarithm | `Log2.Floor`, `Log2.Ceil` | `OPSTATUS` plus output |
| Index | `Index.LSB`, `Index.MSB` | `OPSTATUS` plus output |
| Low bit | `IsolateLowestSet`, `ClearLowestSet` | Value |
| Rotation | `Rotate.Left`, `Rotate.Right` | Value |
| Representation | `ReverseBits`, `ByteSwap` | Value |
| Fields | `Extract`, `Insert` | `OPSTATUS` |

~~~c
uint32_t flags = 0;
OPSTATUS status = MODULE_FUNC(Bit, 32, Set)(&flags, 5U);
if (status == STATUS_CONST(SUCCESS)) {
    bool enabled = MODULE_FUNC(Bit, 32, Check)(flags, 5U);
    uint32_t field = 0;
    status = MODULE_FUNC(Bit, 32, Extract)(flags, 7U, 4U, &field);
    (void)enabled;
}
~~~

Individual-bit indexes are zero-based. Mutating operations validate their value pointer and bit index. Invalid pointers return `INVALID_ARGUMENT`; out-of-range indices return `OUT_OF_RANGE`.

## Masks and fields

The `Mask` variant applies a complete mask with OR, AND-NOT or XOR. `CheckAll` tests whether every mask bit is set, while `CheckAny` tests whether at least one is set. `Mask.Range` constructs an inclusive range mask. `Extract(value, high, low, outField)` reads an inclusive field; `Insert(value, high, low, fieldValue)` replaces it in the pointed-to value. Both validate the endpoints against the selected integer width.

## Counts, indexes and powers of two

`Popcount` counts set bits. Leading/trailing-zero counts are measured within the selected type width and return the full width for zero. `Index.LSB` and `Index.MSB` return `NOT_FOUND` when the input has no set bits. `Log2.Floor` and `Log2.Ceil` likewise return `NOT_FOUND` for zero. `NextPowerOfTwo` returns `ARITHMETIC_OVERFLOW` when the next power cannot fit.

`Rotate.Left` and `Rotate.Right` rotate within the type width. `ReverseBits` reverses bit order; `ByteSwap` reverses byte order.

# Fixed-size bitsets

`Bitset.h` generates objects backed by a compile-time array of `uint64_t` limbs. The header defines `TEMPLATE_Bitset(SUFFIX, BIT_COUNT)` and instantiates its built-in width table.

The object API includes `Clear`, `SetAll`, `And`, `Or`, `Xor`, `Not`, `ShiftLeft`, `ShiftRight`, `Bit.Set`, `Bit.Clear`, `Bit.Flip`, `Bit.Check`, `Bit.Test`, `SetRange`, `ClearRange`, `FlipRange`, `Count`, `Capacity`, `Any`, `All`, `None`, `Equal`, `Is.Subset`, `Is.Disjoint`, `Intersects`, `Find.FirstSet`, `Find.FirstZero` and `Find.NextSet`.

Use a fixed bitset when capacity is known at compile time. Use `Container/Bitset/DynamicBitset.h` when capacity must be selected or resized at runtime; that is a separate Container API.

# Notes

- Scalar packages are generated for 8-, 16-, 32- and 64-bit unsigned integers.
- Range endpoints are inclusive.
- Check `OPSTATUS` before using values returned through output pointers.
- Core Bitset and Container DynamicBitset have different storage and lifetime contracts.
