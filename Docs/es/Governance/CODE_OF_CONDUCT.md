# Código de Conducta

Cosmeron sigue un código de conducta centrado en el respeto, la colaboración técnica constructiva y un entorno inclusivo para todas las personas colaboradoras.

- Trata a todas las personas con respeto y cordialidad.
- Enfócate en críticas técnicas constructivas sobre el código, nunca en ataques personales.
- Sigue las directrices de arquitectura y calidad descritas en `AGENTS.md`.
