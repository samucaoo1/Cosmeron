# Política de seguridad

Cosmeron es actualmente un proyecto experimental y se encuentra en desarrollo activo.

## Cómo informar una vulnerabilidad

No publiques detalles sensibles de vulnerabilidades, credenciales, claves privadas, tokens ni exploits funcionales en una issue pública.

Utiliza la función de este repositorio de **reporte privado de vulnerabilidades**:
abre la pestaña **Security** y selecciona **Report a vulnerability**.

Para mejoras de seguridad que no contengan información sensible, sospechas de errores sin detalles confidenciales o problemas que ya sean públicos, corresponde abrir una issue normal en GitHub.

## Versiones compatibles

Hasta que Cosmeron alcance una versión estable, las correcciones de seguridad se dirigirán a la línea de desarrollo actual. No se garantiza que las revisiones experimentales antiguas reciban backports.
