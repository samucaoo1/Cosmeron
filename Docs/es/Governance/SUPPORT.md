# Soporte

Cosmeron es un proyecto experimental de código abierto que se encuentra en desarrollo activo.

Para defectos reproducibles, utiliza el formulario de issue **Bug report**. Para propuestas relacionadas con APIs, módulos o arquitectura, utiliza el formulario **Feature request**.

Al solicitar ayuda, incluye el contexto mínimo necesario: revisión de Cosmeron, compilador y versión, sistema operativo, ruta de inclusión relevante, comando de compilación y, cuando sea posible, un ejemplo mínimo en C11.

Los informes relacionados con la seguridad deben seguir la [Política de Seguridad](SECURITY.md) y enviarse mediante la función de reporte privado de vulnerabilidades de GitHub, en lugar de una issue pública.

El soporte se ofrece según disponibilidad. Las preguntas cuyas respuestas sean útiles en general podrán incorporarse a la documentación.
