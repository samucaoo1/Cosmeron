# Soporte

Cosmeron es un proyecto experimental de código abierto en desarrollo activo.

Para defectos reproducibles, utiliza el formulario de issue **Bug report**. Para propuestas de API, módulos o arquitectura, utiliza el formulario **Feature request**.

Al solicitar ayuda, incluye el contexto mínimo útil: revisión de Cosmeron, compilador y versión, sistema operativo, ruta de inclusión relevante, comando de compilación y, cuando sea posible, un ejemplo C11 mínimo.

Los informes sensibles de seguridad deben seguir la [Política de seguridad](SECURITY.md) y enviarse mediante la función de informes privados de vulnerabilidades de GitHub, no mediante un issue público.

El soporte se ofrece según disponibilidad. Las preguntas cuyas respuestas sean útiles para otras personas pueden incorporarse a la documentación.
