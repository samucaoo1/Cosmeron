# Código de Conduta

O Cosmeron segue um código de conduta focado em respeito, colaboração técnica construtiva e ambiente inclusivo para todas as pessoas contribuidoras.

- Trate todas as pessoas com respeito e cordialidade.
- Foque em críticas técnicas construtivas sobre o código, nunca em ataques pessoais.
- Siga as diretrizes de arquitetura e qualidade descritas em `AGENTS.md`.
