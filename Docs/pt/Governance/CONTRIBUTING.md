# Guia de Contribuição

Obrigado por contribuir com o Cosmeron!

1. Leia `AGENTS.md` na raiz do repositório para conhecer as regras de DSL, namespaces (`MODULE_*`, `PACKAGE`, `OBJECT`, `STRUCT`, `TEMPLATE_*`) e contratos de função.
2. Mantenha o código em C11 padrão sem dependências externas obrigatórias.
3. Adicione ou atualize testes em `Codespace/Tests/` e exemplos em `Codespace/Examples/`.
4. Verifique se os fluxos de CI em `.github/workflows/` passam antes de abrir seu Pull Request.
