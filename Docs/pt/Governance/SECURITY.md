# Política de Segurança

A Cosmeron é atualmente experimental e está em desenvolvimento ativo.

## Como relatar uma vulnerabilidade

Não publique detalhes sensíveis de vulnerabilidades, credenciais, chaves privadas, tokens ou exploits funcionais em uma issue pública.

Utilize o recurso deste repositório de **comunicação privada de vulnerabilidades**:
abra a aba **Security** e selecione **Report a vulnerability**.

Para reforços de segurança sem informações sensíveis, suspeitas de bugs sem detalhes confidenciais ou problemas já públicos, uma issue normal no GitHub é apropriada.

## Versões com suporte

Até que a Cosmeron alcance uma versão estável, as correções de segurança terão como alvo a linha de desenvolvimento atual. Não há garantia de que revisões experimentais antigas receberão backports.
