# Suporte

A Cosmeron é um projeto experimental de código aberto em desenvolvimento ativo.

Para defeitos reproduzíveis, utilize o formulário de issue **Bug report**. Para propostas relacionadas a APIs, módulos ou arquitetura, utilize o formulário **Feature request**.

Ao pedir ajuda, inclua o menor contexto que seja útil: revisão da Cosmeron, compilador e versão, sistema operacional, caminho de inclusão relevante, comando de compilação e, quando possível, um exemplo mínimo em C11.

Relatos que envolvam segurança devem seguir a [Política de Segurança](SECURITY.md) e ser enviados pelo recurso de comunicação privada de vulnerabilidades do GitHub, em vez de uma issue pública.

O suporte é oferecido conforme a disponibilidade. Perguntas cujas respostas sejam úteis de forma geral poderão ser incorporadas à documentação.
