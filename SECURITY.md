# Security Policy

Cosmeron is under active development. Security reports are welcome and should be handled responsibly.

## Reporting a vulnerability

Do **not** publish sensitive vulnerability details, credentials, private keys, tokens, or working exploits in a public issue.

Use GitHub's **Private vulnerability reporting** for this repository:

**Security → Report a vulnerability**

Include, when possible:

- the affected module or API;
- the affected revision or commit;
- steps to reproduce the issue;
- expected and observed behavior;
- security impact;
- a minimal proof of concept that does not expose third-party systems or data.

For non-sensitive hardening suggestions, ordinary bugs without confidential details, or issues that are already public, a normal GitHub issue is appropriate.

## Supported versions

Until Cosmeron reaches a stable release, security fixes target the current development line. Older experimental revisions are not guaranteed to receive backports.

## Disclosure

Please allow reasonable time for investigation and remediation before public disclosure.
